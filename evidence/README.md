# Verification record

The JSON and log files preserve the original local verification results from 27 November 2026. The hash of `TraceDim.lean` in the repository matches the input hash in [the original review manifest](original-review-manifest.json). The same manifest fingerprints the specific arXiv PDF and TeX audit used in the comparison and records hashes of the original local deliverable under its original filenames. The repository has its own layout, reproduction instructions, and Git history.

The original Lean check used Lean 4.35.0 (commit `eb6cafb7290e8bd5f2937522d8d804f58f02bafc`, arm64 macOS) and Mathlib commit `56a005855ea17e0b0958f73ec801ae140b0a1679`. The original axiom log was generated by appending the three print commands to the file. The repository's wrapper imports the compiled source and prints the same declarations. The numerical checks originally ran with Python 3.13.2, NumPy 2.3.5, SymPy 1.13.3, and mpmath 1.3.0.
